# קבלות הדירה

אפליקציה לפיצול קבלות סופר בין שותפים בדירה.

- **סריקה:** מצלמים קבלה (גם בכמה חלקים), ו-Claude קורא ממנה את הפריטים, המחירים וההנחות.
- **סימון:** כל שותף/ה מסמן/ת את הפריטים שהשתתף/ה בהם. פריט עם כמה שותפים מתחלק שווה בשווה ביניהם.
- **התחשבנות:** רואים מי חייב למי, עם מספר העברות מינימלי, ומסמנים "שולם".

הקובץ `apartment-receipts.html` רץ כ-Artifact ב-claude.ai ומשתמש באחסון משותף (`db`) ובקריאה ל-Claude (`sample`) כדי לקרוא את תמונות הקבלות.
